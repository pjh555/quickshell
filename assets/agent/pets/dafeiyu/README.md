# 大肥鱼角色包

这是 Clavis Agent 的通用桌宠角色包（pet pack），由 `pet.json` 描述渲染器与动画。
放到 `~/.config/clavis/pets/dafeiyu/` 也可以覆盖内置版本。

素材来自 [fatfish-pet-smart-companion](https://github.com/botaochen840-lgtm/fatfish-pet-smart-companion)（MIT），
角色原案 [whale-girl](https://github.com/vlln/whale-girl)（MIT），角色设计 credit：ZipZipPipe。
